RoastBench

An LLM benchmark for roast jokes. Each frontier model writes one roast for each of 10 personalities, at maximum reasoning effort. A human rater drags the jokes into a ranked list per personality and flags any that made them laugh.

Methodology. Each model is invoked at its provider's maximum reasoning tier (Anthropic effort:max, OpenAI reasoning:xhigh, Google thinking_level:high), with no tools or web access. The single prompt is: "Write one roast joke about {name}. It will be your entry into a competitive roast battle judged by humans." A human rater then drags each joke into a per-personality ranked list (best at top); the headline number is the average percentile across personalities. LOL rate is a separate flag for jokes that made the rater laugh out loud.
